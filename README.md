## Projeto Integrador Interdisciplinar — Rokuzen

### Sobre a Empresa

A [Rokuzen](rokuzen.com.br/agendamento) é uma empresa especializada em massoterapia e bem-estar, oferecendo diferentes tipos de massagens e atendimentos relaxantes.
O projeto foi desenvolvido por estudantes do [Instituto Mauá de Tecnologia](https://maua.br/?utm_medium=cpc&utm_source=google&utm_campaign=verao2026_pmax_campus_sp) como parte do Projeto Integrador Interdisciplinar, com o objetivo de modernizar e automatizar o gerenciamento das atividades internas da Rokuzem.

### Objetivo do Projeto

Desenvolver um sistema web que facilite o controle de sessões terapêuticas, gestão de terapeutas e visualização de postos de atendimento, tornando o processo mais ágil, organizado e acessível.


### Tecnologias Utilizadas

[Node.js](https://nodejs.org/en/download.)

[Aiven](https://aiven.io/) 

[MySQL](https://www.mysql.com/)

[Visual Studio Code (VSCode)](https://code.visualstudio.com/download)

HTML5 & CSS3

Extensão Live Server (Go Live)

### Como Executar o Projeto:

1️) Clone o repositório:

git clone https://github.com/LuizaGomes03/PI_.git


2️) Acesse o diretório do projeto:

cd PI_


3️) Instale o Node.js (caso ainda não tenha):

Baixe e instale pelo site oficial: https://nodejs.org

4️) Instale as dependências principais:

npm install


5️) Acesse o diretório do back-end:

cd back_end


6️) Instale os pacotes necessários:

npm install express mysql2 dotenv fs


7️) Inicie o servidor:

npm start


8️) Abra o projeto no VSCode e utilize a extensão Live Server (Go Live) para visualizar a interface no navegador.
